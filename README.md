## ✨ 核心功能亮点

### 1. 📶 真正的无感进出（蓝牙近场解锁）
* **自动解锁/锁车**：利用手机蓝牙实时感知与车辆的距离（RSSI 信号）。您可以自定义“解锁阈值”与“锁车阈值”。
* **告别掏手机**：只需携带手机靠近车辆，走到车门旁自动为您解锁；下车离开车辆一定距离后，自动锁车防盗，优雅且从容。
* **状态精准显示**：界面实时显示“已进入解锁范围”、“处于缓冲区间”、“已离开锁定范围”及精准的信号强度 dBm 值。

### 2. 📱 桌面极速控车（自定义长按快捷键）
* **免进 App 控车**：在手机桌面长按本 App 图标，即可直接弹出车控菜单（支持解锁、锁车、开后备箱、一键透气等）。
* **功能随心定制**：进入 App 控制页右上角 ⚙️（设置），您可以从十余项高级功能中，自由挑选最常用的 4 项固定到您的手机桌面上。

### 3. 🎮 全能硬核车辆控制
* **基础车控**：解锁车门、解锁上电、锁定车辆、打开/关闭后备箱、闪灯鸣笛寻找爱车。
* **车窗魔法**：一键车窗透气（可能部分车辆不支持,自定义降窗幅度需要配置exe的配置文件）、一键全车关窗。
* **独立双区温控**：支持（需车辆硬件支持）主驾/副驾独立的**座椅通风**与**座椅加热**开启及关闭。
* **高级功能**：远程开启/关闭空调、一键熄火、智能判断不重复下发指令。

### 4. 🗺️ 实时车况与 3D 沉浸交互
* **3D 车模展示**：控制页支持下拉手势，深度下拉伴随震动反馈，即可丝滑展开 3D 车况模型，并同步刷新车辆最新状态。
* **行车轨迹与状态**：支持查询近期行车轨迹，全面掌控爱车动态（需在设置中开启）。

## 🛠️ 安装与使用教程

### 💻 1. 前置准备（必看！）
**本 APP 必须搭配专属的 PC 端（EXE）工具才能完整运行相关服务。** 请在手机端安装前，先下载 PC 端工具：

* **网盘提取码**：`czkj`
* **重要说明**：为保障所有功能可以正常使用，请保持PC端和手机端的程序都是最新版本！

### 📥 2. 如何下载安装 APP？
请点击本页面右侧的 **[Releases](https://github.com/Qcby/Bydkz/releases)** 标签，找到带有一个绿色 `Latest` 标志的最新版本。展开 `Assets`，点击下载 `Bydkz-Qcby-vX.X.X.apk` 安装到您的安卓手机中。

### ⚙️ 3. 初始权限设置（非常重要！）
为了保证“近场无感解锁”功能在您锁屏装在口袋里时依然有效，请务必给 App 赋予以下权限：
1. **位置信息权限**：选择“始终允许”（用于后台扫描低功耗蓝牙）。
2. **附近设备权限**：允许（用于连接车辆蓝牙）。
3. **电池优化白名单**：在手机设置中，将本 App 的省电策略设为“无限制”或“允许后台高耗电”。
4. **锁定后台**：在手机的最近任务（多任务）卡片界面，将本 App 下拉加锁（显示小锁头图标），防止被系统杀后台。

### 📏 4. 调整近场感应阈值
由于不同型号手机的蓝牙天线强度不同，初次使用建议进行校准：
* 拿着手机站在车门旁（您希望解锁的距离），观察 App 上的信号强度（例如 -70dBm），将**解锁阈值**设置为该数值左右。
* 走到离车 5~10 米外（您希望锁车的距离），观察信号强度（例如 -90dBm），将**锁定阈值**设置为该数值。
* *注：解锁阈值必须大于锁定阈值（例如：解锁 -75，锁定 -88）。*
